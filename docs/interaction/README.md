## Interaction Types Summary

| Type | Pattern | Best For |
|------|---------|----------|
| **Sequential** | Linear chain (A → B → C) | Pipeline processing, step-by-step refinement |
| **Group Discuss** | Multi-agent collaboration | Multi-perspective analysis, consensus building |
| **Workflow Suggestion** | Dynamic optimization | Data pipelines, prompt chain refinement |

## Key Concepts

- **One-by-One**: Sequential processing where output feeds input
- **Group Discuss**: Mesh/hub-spoke/hierarchical structures with consensus
- **Workflow Suggestion**: Value addition at each step in data/prompt chain
